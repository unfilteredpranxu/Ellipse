# Study and Calendar feature matrix

| Feature | Delivery |
| --- | --- |
| Calendar | Day, week, and month with selected-day agenda. Create, edit, move by date, duplicate and delete tasks. Subject, priority, estimate, optional clock time and links. Daily/weekly occurrence completion and skip exceptions. |
| Focus | Full-page and optional Notes timer share the native vault. Presets, custom duration, stopwatch, manual breaks, pause, resume, finish and links. Time is monotonic for the active segment while mounted and rebuilt from UTC wall time on reopen. |
| Analytics | Completed intervals split on device-local date boundaries. Weekly daily and subject totals, break totals, and weekly goal. Finishing a session leaves task completion unchanged. |
| Exam and progress | Main, Main+Advanced, NEET, target year, preserved switching, personal unit/topic groups, five progress states, weak flag, revision task and Focus linkage. |
| Official seed and countdown | Blocked by HTTP 403 on official sites. No official topics or dates are seeded. See [source audit](OFFICIAL_SOURCES.md). |
| Follow-on | Complex recurrence rule editing, native reminders, subtasks, manual time correction/audit, automatic Pomodoro cycles, idle detection, Focus wallpaper and sound, exam crosswalk and officially sourced version migration. |
